🎓 Panel de Clase: Configuraciones de Seguridad en Supabase

Explicación de las opciones al crear un proyecto conectado a GitHub Pages

1. Enable Data API

Recomendado: Activado ✅

Qué es: Genera automáticamente una API REST sobre tu base de datos PostgreSQL utilizando PostgREST.

Por qué usarse: Es indispensable para sitios estáticos en GitHub Pages. Permite que el frontend consulte o inserte datos directamente mediante solicitudes HTTP utilizando la librería de JavaScript.

2. Automatically expose new tables

Recomendado: Desactivado ❌

Qué es: Otorga permisos automáticos a los roles de la API pública cada vez que creas una tabla nueva.

Por qué usarse: Sigue el principio de mínimo privilegio. Si se deja activo, cualquier tabla nueva que crees quedará expuesta públicamente por defecto. Desactivarlo te obliga a dar permisos de manera consciente.

3. Enable automatic RLS (Row Level Security)

Recomendado: Activado ✅

Qué es: Un disparador (trigger) que activa automáticamente la seguridad a nivel de fila en cada tabla nueva.

Por qué usarse: Actúa como red de seguridad. Evita que una tabla expuesta en la API entregue información a menos que existan políticas (Policies) explícitas que autoricen la lectura o escritura de datos.
